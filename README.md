# The Rift University (TRU)

A modern African-inspired online university platform built with Next.js, TypeScript, and Tailwind CSS.

## Phase 1-3 Delivery Summary

This repository contains the initial foundation for The Rift University and includes:

- Phase 1: project discovery, architecture, roadmap, governance, and stack definition
- Phase 2: TRU brand identity, design system, color palette, and UI tokens
- Phase 3: public website landing experience with key sections for admissions, faculties, and support

## Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- PostCSS
- Node.js 18+

## Quick start

```bash
npm install
npm run dev
```

Then open http://localhost:3000
