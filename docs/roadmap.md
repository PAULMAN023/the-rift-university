# The Rift University (TRU)

## Project overview

The Rift University is an African-rooted digital university platform designed for modern education, innovation, leadership, and scalable online learning.

## Phase 1: Project discovery and technical planning

Completed in this initial repository version:

- Project charter and institutional identity
- Technology stack and architecture overview
- Database architecture proposal
- Development roadmap and phased delivery plan
- Baseline repository structure and environment configuration

## Phase 2: TRU branding and design system

Included in this phase:

- Institutional color palette
- Typography and visual identity guidance
- Reusable UI tokens and accents
- Design direction aligned to African savanna-inspired themes

## Phase 3: Public website foundation

Included in this phase:

- Public landing page for TRU
- Hero section with institutional messaging
- Academic school highlights
- Student experience overview
- Admissions call-to-action
- Contact and footer sections

## Implementation notes

This repository is intentionally structured as a secure beginning for a larger platform. Some details remain placeholders pending verification by institutional leadership and approved policies.

## Future phases

The roadmap continues through authentication, academic catalogue, LMS, assessments, certificates, staff and admin portals, AI features, finance, and deployment.
